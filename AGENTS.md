# Agent Guidelines

## Language and Documentation Rules

- **Issues, Pull Requests, and Documentation**: Must be written in both English and Japanese.
  - Japanese text must be placed inside `<details>` tags so that it is inconspicuous.
- **Code Comments**: Must be written in English only.
